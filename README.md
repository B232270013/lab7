## 1. Зорилго

Энэхүү лабораторийн ажлын зорилго нь «Уншлагын жагсаалт» веб аппликейшнд Session-Based Test Management (SBTM) аргыг ашиглан exploratory тест гүйцэтгэх, ажиглагдсан согогуудыг илрүүлж баримтжуулахад оршино.

Лабораторийн хүрээнд:

- Тестийн зорилго, хамрах хүрээг тодорхойлж Charter боловсруулсан.
- 60 минутын exploratory testing session зохион байгуулсан.
- Туршилтын явцад бодит цагийн тэмдэглэл хөтөлсөн.
- Илэрсэн согогуудыг BUG дугаараар бүртгэсэн.
- Screenshot болон API-ийн curl гаралтыг нотолгоо болгон хадгалсан.
- Session report, bug report, дүгнэлт боловсруулсан.

## 6. API туршилтын нотолгоо

Saboteur Tour-ийн хүрээнд дараах хүсэлтийг илгээсэн.

```bash
curl -i -X POST http://localhost:3000/api/books \
  -H "Content-Type: application/json" \
  --data-binary 'invalid json'
```

**Хүлээгдсэн үр дүн:**

```text
HTTP/1.1 400 Bad Request
```

**Бодит үр дүн:**

```text
HTTP/1.1 200 OK
Content-Type: application/json

{"result":"OK"}
```

Энэ нь буруу бүтэцтэй JSON хүсэлтийг сервер амжилттай гэж боловсруулж байгааг харуулсан.

Бүтэн нотолгоо: [evidence/bug-07-curl.txt](evidence/bug-07-curl.txt)

## 9.Дүгнэлт

1. Энэхүү лабораторийн ажлын хүрээнд «Уншлагын жагсаалт» веб аппликейшнд exploratory testing хийж, нийт 10 тест гүйцэтгэснээс 9 ялгаатай согогийн ажиглалт бүртгэсэн.
2. Хамгийн үр дүнтэй нь Fed-Ex Tour байсан бөгөөд нийт номын тоолуурын BUG-04, давхардсан номын BUG-05, хайлтын BUG-06, тусгай тэмдэгтийн BUG-09 согогуудыг илрүүлсэн.
3. Couch Potato Tour ашиглан бүх талбар хоосон байхад ном нэмэгдэж байгаа BUG-01 согогийг илрүүлсэн.
4. Antisocial Tour ашиглан зөвшөөрөгдөөгүй 999 онтой ном нэмэгдэж байгаа BUG-02 согогийг илрүүлсэн.
5. Supermodel Tour ашиглан оны формат буруу харагдах BUG-03 болон устгах үйлдлийн тохирох мессеж гарахгүй байгаа BUG-08 согогуудыг ажигласан бөгөөд урт текстийн TC-09 туршилтаар хүснэгтийн бүтэц эвдрээгүй.
6. Saboteur Tour ашиглан API-д эвдэрхий JSON илгээхэд HTTP 400-ийн оронд HTTP 200 буцааж байгаа BUG-07 согогийг илрүүлж, curl командын бүтэн гаралтыг нотолгоо болгон хадгалсан.
7. Анхны charter-д төлөвлөсөн аяллуудаас гадна Antisocial болон Fed-Ex Tour-ийг ашигласнаар нэмэлт согогуудыг илрүүлсэн.
8. Зохиолчийн нэрээр хайх, бүх хуудас болон холбоосыг шалгах зэрэг туршилтууд бүрэн хийгдээгүй тул дараагийн session-ийн charter-т тусгах шаардлагатай.
9. BUG-01, BUG-02, BUG-03, BUG-04, BUG-05, BUG-06, BUG-08, BUG-09 согогуудыг тохирох шалгалттай Playwright тестээр, BUG-07-г HTTP статус шалгах API автомат тестээр илрүүлэх боломжтой.
10. Энэ session-д Playwright автомат тест ажиллуулаагүй бөгөөд зөвхөн хүний нүдээр л илрүүлэх боломжтой гэж батлагдсан тусдаа согог бүртгэгдээгүй.

SBTM арга нь урьдчилан тодорхойлсон charter-ийн хүрээнд туршилт гүйцэтгэхийн зэрэгцээ шинэ асуудал илэрвэл түүнийг судлах боломж олгосон.Туршилтын явцад оролтын баталгаажуулалт, өгөгдлийн бүрэн бүтэн байдал, хайлтын ажиллагаа, текстийн дүрслэл, API-ийн алдааны боловсруулалттай холбоотой зөрчлүүд ажиглагдсан.Илэрсэн согогуудыг дэлгэрэнгүй bug report, screenshot болон API-ийн бодит гаралтаар баримтжуулсан бөгөөд цаашид эдгээр согогийг зассаны дараа regression testing хийх шаардлагатай.
