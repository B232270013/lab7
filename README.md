## Хэсэг E: Дүгнэлт (Debrief)

1. Lab 07-ийн хүрээнд «Уншлагын жагсаалт» веб аппликейшнд 60 минутын Exploratory Testing session хийж, нийт 5 ялгаатай согог илрүүлсэн.Хамгийн үр дүнтэй нь Fed-Ex аялал байсан бөгөөд энэ аргаар давхардсан ном нэмэгдэж байгаа (BUG-03) болон хайлт том, жижиг үсэг ялгаж байгаа (BUG-05) согогуудыг илрүүлсэн.Couch Potato аяллаар бүх талбар хоосон байхад ном нэмэгдэж байгаа (BUG-01) согогийг илрүүлсэн.Antisocial аяллаар зөвшөөрөгдөөгүй 999 онтой ном нэмэгдэж байгаа (BUG-02) согогийг илрүүлсэн.Saboteur аяллаар буруу JSON өгөгдөлтэй POST хүсэлтэд HTTP 400-ийн оронд HTTP 200 буцааж байгаа (BUG-04) согогийг илрүүлж, curl командын гаралтыг нотолгоо болгон хадгалсан.Анхны charter-д тусгагдсан Couch Potato, Supermodel, Saboteur аяллуудаас гадна Antisocial болон Fed-Ex аяллуудыг ашиглан нэмэлт согогууд илрүүлсэн.Session-ийн тэмдэглэлд Supermodel аяллын үр дүн бүртгэгдээгүй тул интерфейсийн өнгө, текстийн алдаа, урт оролтын харагдацыг шалгасан гэж дүгнэх боломжгүй.Мөн ном устгах үйлдэл, нийт номын тоолуур болон бүх хуудас, линкүүдийн ажиллагаа шалгагдаагүй үлдсэн тул дараагийн session-ийн charter-т эдгээрийг тусгах шаардлагатай.Илрүүлсэн BUG-01, BUG-02, BUG-03, BUG-05 согогуудыг тохирох тестийн оролт, хүлээгдсэн үр дүнгийн шалгалт бичсэн тохиолдолд Лаб 1-д ашигласан Playwright хэрэгслээр автомат тест болгон илрүүлэх боломжтой бөгөөд BUG-04-ийг API-ийн HTTP статус шалгах автомат тестээр илрүүлэх боломжтой.Энэ session-д Playwright автомат тест ажиллуулаагүй, мөн зөвхөн хүний нүдээр илрэх UI-ийн согог бүртгэгдээгүй учраас эдгээр таван согогийн аль нэгийг зөвхөн хүний нүдээр илрүүлэх боломжтой гэж үзээгүй.
